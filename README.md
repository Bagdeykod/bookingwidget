# 📅 Booking Widget — Виджет онлайн-записи

![Node.js](https://img.shields.io/badge/Node.js-18+-339933?style=flat&logo=node.js&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-F7DF1E?style=flat&logo=javascript&logoColor=black)

![Telegram](https://img.shields.io/badge/Telegram-Bot_API-26A5E4?style=flat&logo=telegram&logoColor=white)

Современный веб-виджет для онлайн-записи клиентов на услуги с автоматической интеграцией Telegram-бота, защитой от двойного бронирования и защищённой панелью управления.

---

## 🎯 О проекте

**Booking Widget** — это готовое решение для автоматизации записи клиентов, которое:

- ✅ Позволяет клиентам самостоятельно записываться на услуги через удобную веб-форму
- ✅ **Защищает от двойного бронирования** — проверяет занятость времени перед созданием записи
- ✅ Мгновенно отправляет уведомления о новых записях в Telegram
- ✅ Сохраняет все записи в облачном хранилище (Vercel KV)
- ✅ Предоставляет защищённую панель управления для владельца
- ✅ Работает без сервера (serverless-архитектура)

**Идеально подходит для:** мастеров красоты, фитнес-тренеров, фотографов, консультантов, репетиторов и любых специалистов, предоставляющих услуги по записи.

## ✨ Ключевые возможности

### Для клиентов:
- 📱 **Адаптивный дизайн** — работает на любых устройствах (desktop, tablet, mobile)
- 🎨 **Современный UI** — стиль Apple Design с glassmorphism-эффектами
- ⚡ **Мгновенная обратная связь** — модальное окно с подтверждением записи
- 🛡️ **Защита от спама** — honeypot-поле и rate limiting

### Для владельца:
- 📊 **Панель управления** — просмотр всех записей с фильтрацией по датам

### Техническая сторона:

- 💾 **Облачное хранилище** — Vercel KV (Redis) для хранения записей
- 🚫 **Защита от двойных записей** — проверка доступности слота перед бронированием

- 📈 **Масштабируемость** — готовность к росту нагрузки
- 🌍 **CDN** — быстрая загрузка из любой точки мира

## 📐 Архитектура

```
┌─────────────────────────────────────────────────────┐
│                   КЛИЕНТ (Browser)                   │
│  ┌─────────────────┐      ┌─────────────────┐       │
│  │  index.html     │      │  admin.html     │       │
│  │  (Форма записи) │      │  (Панель админа)│       │
│  └────────┬────────┘      └────────┬────────┘       │
└───────────┼─────────────────────────┼────────────────┘
            │                         │
            │ POST /api/send          │ GET/DELETE /api/bookings
            │                         │
┌───────────▼─────────────────────────▼────────────────┐
│              VERCEL SERVERLESS FUNCTIONS              │
│  ┌──────────────────┐      ┌──────────────────┐     │
│  │  send.js         │      │  bookings.js     │     │
│  │  - Валидация     │      │  - Авторизация   │     │
│  │  - Проверка слота│      │  - CRUD записей  │     │
│  │  - Rate limiting │      │  - Фильтрация    │     │
│  │  - Honeypot      │      │                  │     │
│  └────────┬─────────┘      └────────┬─────────┘     │
└───────────┼─────────────────────────┼────────────────┘
            │                         │
            │                         │
     ┌──────▼──────┐           ┌──────▼──────┐
     │  Telegram   │           │  Vercel KV  │
     │  Bot API    │           │   (Redis)   │
     │ (Уведомления)│          │ (Хранилище) │
     └─────────────┘           └─────────────┘
```

### Поток данных:

1. **Новая запись:**
   - Клиент заполняет форму на `index.html`
   - `send.js` валидирует данные, проверяет rate limit и honeypot
   - **Проверяет доступность слота времени** — если занято, возвращает HTTP 409
   - Если свободно — отправляет уведомление в Telegram
   - Сохраняет запись в Vercel KV

2. **Просмотр записей:**
   - Админ вводит токен на `admin.html`
   - `bookings.js` проверяет токен (timing-safe)
   - Загружает записи из Vercel KV
   - Отображает с группировкой по датам и фильтрацией

3. **Отмена записи:**
   - Админ нажимает "Отменить" в панели
   - `bookings.js` обновляет статус на `cancelled`
   - Запись помечается как отменённая (не удаляется физически)

## 📦 Установка и запуск

### Предварительные требования

- **Node.js** версии 18 или выше ([скачать](https://nodejs.org/))
- **npm** (устанавливается вместе с Node.js)
- Аккаунт **Telegram** и созданный бот через [@BotFather](https://t.me/BotFather)
- Аккаунт **Vercel** ([зарегистрироваться](https://vercel.com/signup))

### 1. Клонирование репозитория

```bash
git clone https://github.com/ваш-username/booking-widget.git
cd booking-widget
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка переменных окружения

Скопируйте файл `.env.example` в `.env`:

```bash
cp .env.example .env
```

Откройте `.env` и заполните переменные:

```env
# Токен Telegram-бота (получите у @BotFather)
BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11

# ID чата для уведомлений
# Личный чат: узнайте свой user ID через @userinfobot
# Группа/канал: добавьте бота и получите chat ID через @getidsbot
CHAT_ID=123456789

# Токен доступа к админ-панели (сгенерируйте случайную строку)
# Linux/macOS: openssl rand -hex 32
# Windows: -join ((48..57) + (65..90) + (97..122) | Get-Random -Count 64 | % {[char]$_})
ADMIN_TOKEN=ваш_сгенерированный_токен
```

#### Как получить BOT_TOKEN:
1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям (придумайте имя и username)
4. Скопируйте полученный токен

#### Как получить CHAT_ID:
**Для личного чата:**
1. Найдите [@userinfobot](https://t.me/userinfobot) в Telegram
2. Нажмите "Start" или отправьте любое сообщение
3. Скопируйте ваш `Id` (числовое значение)

**Для группы/канала:**
1. Добавьте вашего бота в группу/канал
2. Найдите [@getidsbot](https://t.me/getidsbot) и добавьте в ту же группу
3. Скопируйте `Chat ID` (начинается с `-`)
4. Удалите @getidsbot из группы (опционально)

### 4. Локальный запуск

```bash
npm run dev
```

Проект запустится на `http://localhost:3000`:
- Виджет записи: http://localhost:3000/
- Админ-панель: http://localhost:3000/admin.html
- Serverless-функции будут эмулироваться локально

**Важно**: для работы с Vercel KV локально создайте файл `.env.local` с переменными из Vercel Dashboard.

## 🚀 Деплой на Vercel

### Быстрый старт (через Git — рекомендуется)

1. **Создайте репозиторий на GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ваш-username/ваш-репо.git
   git push -u origin main
   ```

2. **Подключите в Vercel:**
   - Откройте [Vercel Dashboard](https://vercel.com/dashboard)
   - **Add New** → **Project**
   - Выберите ваш GitHub-репозиторий
   - Vercel автоматически определит настройки
   - Нажмите **Deploy**

3. **Настройте Vercel KV:**
   - В настройках проекта → **Storage** → **Create Database** → **KV**
   - Создайте KV store (например, `bookings-db`)
   - Vercel автоматически добавит переменные `KV_REST_API_*`

4. **Добавьте переменные окружения:**
   - **Settings** → **Environment Variables**
   - Добавьте: `BOT_TOKEN`, `CHAT_ID`, `ADMIN_TOKEN`

5. **Готово!** Каждый push в `main` автоматически деплоится

### Через Vercel CLI

1. **Установите Vercel CLI:**
   ```bash
   npm install -g vercel
   ```

2. **Войдите в аккаунт:**
   ```bash
   vercel login
   ```

3. **Задеплойте:**
   ```bash
   npm run deploy
   # или
   vercel --prod
   ```

4. **Настройте переменные окружения:**
   ```bash
   vercel env add BOT_TOKEN
   vercel env add CHAT_ID
   vercel env add ADMIN_TOKEN
   ```

5. **Создайте Vercel KV** через Dashboard (см. выше)

## 📖 Использование

### Для клиентов

1. Откройте виджет по адресу вашего сайта
2. Выберите услугу из выпадающего списка
3. Укажите желаемую дату и время
4. Введите имя и Telegram-username
5. Нажмите "Записаться"
6. Получите подтверждение в модальном окне

### Для владельца

1. Откройте админ-панель: `https://ваш-проект.vercel.app/admin.html`
2. Введите ваш `ADMIN_TOKEN`
3. Просматривайте все записи:
   - Записи группируются по датам
   - Сегодняшние записи выделены
   - Прошедшие записи затемнены
4. Фильтруйте по диапазону дат (опционально)
5. Отменяйте записи кнопкой "Отменить"

При каждой новой записи бот отправит сообщение:

```

📅 Дата и время: четверг, 14 августа 2026 г., 14:30
👤 Имя: Анна
💬 Telegram: @anna_example
```

## 🔒 Безопасность

Проект реализует несколько уровней защиты:

### Защита от автоматизированных атак
- **Honeypot-поле** — скрытое поле `website`, которое заполняют только боты
- **Rate limiting** — максимум 5 запросов в минуту с одного IP
- **Валидация на сервере** — проверка формата всех полей (дата, время, Telegram)

### Защита данных
- **Санитизация HTML** — удаление тегов из пользовательского ввода
- **Timing-safe сравнение** — защита токена от timing-атак
- **Переменные окружения** — все секреты хранятся безопасно

### HTTP Security Headers
- `X-Frame-Options: DENY` — защита от clickjacking
- `X-Content-Type-Options: nosniff` — защита от MIME-снифинга
- `X-XSS-Protection` — базовая защита от XSS
- `Referrer-Policy` — контроль передачи referrer
- `X-Robots-Tag` — блокировка индексации админ-панели

### Рекомендации
- ✅ Используйте сложный `ADMIN_TOKEN` (минимум 32 символа)
- ✅ Не коммитьте `.env` или `.env.local` файлы в git
- ✅ Регулярно обновляйте зависимости: `npm update`
- ✅ Мониторьте логи Vercel Functions на подозрительную активность
- ✅ Проверка дубликатов работает на уровне функции, но при одновременных запросах возможны race conditions — для критичных случаев рассмотрите транзакционные механизмы
